# Optimization Algorithms

Optimization lies at the heart of many problems in science, engineering, and everyday applications. The scripts in this repository are designed to illustrate different strategies for reaching optimal—or near-optimal—solutions.

## Content

- **Basic implementations of various optimization algorithms.**
- **The code is organized for easy readability and extensibility.**

## Notebooks

- **Damian_Tamburi_GA1.ipynb** – Guided Activity 1: Towers of Hanoi (divide and conquer), coin change (greedy), N-Queens (backtracking), river trip (dynamic programming) and closest pair of points (brute force vs. divide and conquer).
- **Damian_Tamburi_GA2.ipynb** – Guided Activity 2: dynamic programming, task assignment with branch and bound, complexity study and gradient descent.
- **Damian_Tamburi_GA3.ipynb** – Guided Activity 3: Traveling Salesman Problem (TSPLIB `swiss42`) with random search, local search, variable neighborhood search and simulated annealing.
- **Final_Project_Algorithms_TAMBURI.ipynb** – Final project: scheduling dubbing sessions to minimize actor costs using random search, tabu search and simulated annealing.
